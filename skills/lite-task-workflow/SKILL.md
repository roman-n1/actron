# Light-цикл

Адаптирован из одноимённого skill KMP Messenger. Новая самостоятельная цель начинает цикл;
уточнения и статус продолжают текущий. Кратко обозначь применение, без обязательного отчёта-файла.

1. Определи результат, границы и критерий готовности по запросу и коду.
2. До реализации выбери проверки поведения, API и применимых платформ. Для нового поведения
   сначала различающий тест; для рефакторинга сначала существующие тесты.
3. Прочитай зонный skill. Для выбора ответственности —
   [high-cohesion-low-coupling](../high-cohesion-low-coupling/SKILL.md).
4. Выполни работу. Продуктовые неизвестные уточняй, технические детали выбирай сам.
5. Проверь результат по [AGENTS.md](../../AGENTS.md), сообщи реальные результаты и ограничения.

Tacticum, внешняя KB, новый чат и дополнительные агенты не являются условием работы.
Сам цикл не разрешает commit/push/публикацию. Мутационный раннер пока не подключён:
не копируй обещание обязательного успешного M из мессенджера.
Для долгой задачи полезен локальный checkpoint: цель, решения, проверки, остаток и следующий шаг.
